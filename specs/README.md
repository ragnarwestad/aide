# Reports

This directory contains AI-generated reports and analysis documentation.

## 📁 Structure

```text
reports/
├── jira/           # JIRA issues (generated by /aide-create, /aide-analyze)
│   └── PROJ-XXXX/
│       ├── README.md           # Entry point with reading order
│       ├── 1-description.md    # JIRA metadata + problem description
│       ├── 2-analysis.md       # Codebase analysis
│       ├── 3-solution.md       # Implementation plan (TDD)
│       └── 4-status.md         # Progress tracking
│
└── todo/           # TODO plans (generated by /aide-create, /aide-analyze)
    ├── 01-redux-form-migration/
    │   ├── README.md           # Entry point with reading order
    │   ├── 1-description.md    # High-level description
    │   ├── 2-analysis.md       # Codebase analysis + estimates
    │   ├── 3-solution.md       # Migration plan
    │   └── 4-status.md         # Progress tracking
    └── 17-step-selector-analysis/
        └── ...
```

## 🎯 Difference between JIRA and TODO

| Aspect       | JIRA issues                                          | TODO plans                       |
|--------------|------------------------------------------------------|----------------------------------|
| **Source**   | JIRA API (external)                                  | Created manually                 |
| **Scope**    | Specific feature/bug                                 | Larger migration/improvement     |
| **Workflow** | `/aide-create` → `/aide-analyze` → `/aide-implement` | `/aide-create` → `/aide-analyze` |

## 📚 Documentation standards

See [../core/rules/documentation.md](../core/rules/documentation.md) for the complete documentation standard.

**Both follow the same 5-file structure:**
1. `README.md` - Entry point (links to the files in the right reading order)
2. `1-description.md` - Entry (problem, scope, acceptance criteria)
3. `2-analysis.md` - Detailed analysis (findings, complexity, risk)
4. `3-solution.md` - Implementation plan (TDD approach)
5. `4-status.md` - Progress (⬜ 🔄 ✅ ❌ ⚠️)

## 🔄 Workflow

### JIRA issues

```bash
# 1. Create documentation
/aide-create PROJ-XXXX

# 2. Analyze codebase
/aide-analyze PROJ-XXXX

# 3. Implement solution (TDD-assisted)
/aide-implement PROJ-XXXX
```

### TODO plans

```bash
# 1. Create description.md manually
/aide-create "Title" "Detailed description"

# 2. Analyze codebase
/aide-analyze 17
```
